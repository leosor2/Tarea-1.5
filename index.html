Qué son los elementos semánticos

Los elementos semánticos de HTML5 describen el significado y la función del contenido que contienen. A diferencia de div y span, permiten identificar mejor cada parte de una página web.

Algunos elementos semánticos son header, nav, main, section, article, aside y footer. Cada uno se utiliza para organizar un tipo concreto de contenido.
